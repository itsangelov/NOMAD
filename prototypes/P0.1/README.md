# P0.1 — Mechanical Proof of Concept

**Goal:** a mechanically coherent, parametric, printable chassis concept. It does not need to look good.

> **Architecture update (D-010, 2026-10-01):** B1 (one solar leaf behind the lid) is the selected V1 architecture. The cassette questions below ("Can the cassettes slide / rotate / lock?") belong to Architecture A, superseded / deferred for V1. For B1 the equivalent questions are the hinge, motion, cable, stay and thermal gates in `docs/v1-requirements.md` §8. The status line below is historical: Rounds A–E and the D-010 studies have since been modeled (see `docs/build-log.md`); nothing is physically tested.

## Questions P0.1 must answer

- [ ] Do the proportions work?
- [ ] Do the major component envelopes fit?
- [ ] Does the keyboard/trackpad/display layout work?
- [ ] Does the solar cassette concept work?
- [ ] Can the cassettes slide?
- [ ] Can they rotate?
- [ ] Can they lock?
- [ ] Can the mechanism be printed?
- [ ] Can the machine be serviced?
- [ ] Is there enough space for electronics?
- [ ] Is there enough space for wiring?
- [ ] Is there enough cooling volume?

For each answer, record whether it was modeled, simulated, inferred, physically tested or measured.
