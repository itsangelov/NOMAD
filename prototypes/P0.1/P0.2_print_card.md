# NOMAD P0.2 — Print Card (FDM test coupons)

> **SUPERSEDED / DEFERRED FOR NOMAD V1 (D-010, 2026-10-01).** This record belongs to **Architecture A** (sliding/tilting solar cassettes and their lid, D-004 / D-009). The owner selected **Architecture B1** (one solar leaf behind the display lid) as the active V1 architecture. The content below is kept unchanged as an engineering record and possible later reference; it does not describe the V1 design. See `docs/decisions.md` D-010 and `docs/v1-requirements.md`.

**Files:** `CAD/coupons/P0.2/print_order/NOMAD_P02_*.stl`
- These are copies of the canonical STLs; the originals in `CAD/coupons/P0.1/stl` and `CAD/coupons/P0.2/stl` are unchanged.
- Units are **millimetres**. Every file is already in print orientation: Z is up, and the part sits on Z = 0.
- These are engineering test parts. **Print them exactly as supplied.**

## Mandatory settings
| Setting | Requirement |
|---|---|
| Material | **PETG**. Use one spool / brand / colour for all parts; natural or translucent preferred. |
| Nozzle | 0.4 mm |
| Layer height | **0.20 mm** (not 0.28 / 0.3) |
| Scaling | **None.** No "fit to bed", no auto-scale, no unit conversion. Keep the STL dimensions in mm. |
| Orientation | **As supplied.** No auto-orient, no rotation about X/Y. Rotation about Z to fit the bed is allowed. |
| Supports | **None, for every part.** No raft. A brim is allowed on long parts if it is removed cleanly. |
| Perimeters | ≥ 3 walls on all parts; ≥ 4 around the insert holes on B_FRAME |
| Top / bottom | ≥ 6 solid layers (1.2 mm) |
| Model repair | Don't alter the geometry. The files are watertight; internal cavities in BS30 / BS20 are intentional. |
| Accuracy | Dimensions ± 0.2 mm; flat faces flat. Don't enlarge holes. |

## Estimates (not quotes)
| | MIN | REC |
|---|---|---|
| Parts | 9 | 14 |
| PETG (density 1.27 g/cm³ assumed) | ~384 g | ~593 g |
| Machine time (at ~14 g/h, inferred) | ~27 h | ~42 h |

- **Minimum bed:** 235 × 95 mm (230 × 90 plates + ~5 mm margin). A 220 × 220 bed is too small.
- The whole set **will not fit on one plate** of a 250 mm-class bed. It needs several plates: roughly two 230 × 90 plates per plate on a ~250 × 210 bed. One order is fine.
